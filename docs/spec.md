# ポモドーロタイマー 仕様書

会社PCで、就業時間中だけ自動でポモドーロタイマーを回し、作業と休憩の切り替えをWindows通知で知らせる常駐アプリ。

## 1. 要件

| No. | 項目 | 内容 |
|---|---|---|
| 1 | ポモドーロ | 25分作業 → 5分休憩をくり返す（25分・5分は固定）。4サイクルごとに長い休憩（初期値15分、設定で変更可） |
| 2 | 通知 | 作業終了時・休憩終了時・昼休憩開始時・終業時にWindows通知を出す。通知音はWindows標準 |
| 3 | 稼働日 | 平日のみ。土日・祝日は止める（祝日データはアプリに同梱） |
| 4 | 稼働時間 | 就業開始・終了時刻を手入力で設定（初期値 9:00 / 17:45） |
| 5 | 昼休憩 | 開始・終了時刻を手入力で設定（初期値 12:00 / 13:00）。時刻になったら強制停止し、明けたら1サイクル目から再開 |
| 6 | 自動開始 | 就業開始時刻に自動でスタート。途中で起動した場合は、その時点から1サイクル目を開始 |
| 7 | 終業時 | 終了時刻になったら、サイクルの途中でも強制終了 |
| 8 | ON/OFF | 画面からON/OFFできる。OFFにしても翌営業日には自動でONに戻る |
| 9 | ロック・スリープ中 | タイマーは時刻どおりに進み続ける |
| 10 | 画面表示 | 残り時間、状態、何サイクル目か |
| 11 | 常駐 | タスクトレイに常駐。Windowsログイン時の自動起動は設定で選べる（初期値OFF） |
| 12 | 動作環境 | 会社のWindows PC。.NET同梱の単一exeで配布 |
| 13 | 会社独自の休日 | 年末年始などはON/OFFボタンで止める運用（アプリ側の対応なし） |
| 14 | ミニ表示 | タスクバーのすぐ上に小さな表示を常駐（状態の色・残り時間・サイクル数）。表示・非表示を設定で切り替え可能 |
| 15 | 二重起動防止 | すでに起動中なら、2つ目は何もせず終了する |

## 2. 状態

| 状態 | 意味 | 長さ |
|---|---|---|
| 待機 | 時間外・休日・昼休憩中（理由を区別して持つ） | — |
| 作業中 | 作業時間 | 25分 |
| 休憩 | 1〜3サイクル目の作業後 | 5分 |
| 長い休憩 | 4サイクル目の作業後 | 15分（設定値） |
| OFF | ユーザーが手動で停止 | — |

## 3. 状態遷移と通知

| 遷移元 | 遷移先 | きっかけ | 通知文言 |
|---|---|---|---|
| 待機 | 作業中 | 就業開始時刻・昼休憩明け、または就業時間内に起動 | 作業開始 |
| 作業中 | 休憩 | 25分経過（1〜3サイクル目） | 休憩しましょう |
| 作業中 | 長い休憩 | 25分経過（4サイクル目） | 長い休憩です |
| 休憩・長い休憩 | 作業中 | 休憩時間の経過（長い休憩の後はサイクル数を1に戻す） | 作業再開 |
| 作業中・休憩・長い休憩 | 待機 | 昼休憩開始時刻 | お昼休憩です |
| 作業中・休憩・長い休憩 | 待機 | 終業時刻 | お疲れさまでした |
| 作業中・休憩・待機 | OFF | OFFボタン | なし |
| OFF | 作業中 または 待機 | ONボタン（就業時間内なら1サイクル目から開始） | 作業中になる場合は「作業開始」 |
| OFF | 待機 | 日付が変わったとき | なし |
| すべての状態 | 作業中 または 待機 | タイマーの計算に関わる設定（就業開始・終了、昼休憩の開始・終了、長い休憩の長さ）を変えて保存（ONにし直したときと同じ扱い。就業時間内なら1サイクル目から開始） | 作業中になる場合は「作業開始」 |

## 4. 計算ルール

- カウントダウンを積み上げず、「区間の開始時刻」と現在時刻の差から状態を逆算する
- 1日を午前（就業開始〜昼休憩開始）と午後（昼休憩終了〜就業終了）の2区間に分ける
- 区間の開始時刻 ＝「区間の始まり」と「起動した時刻・ONにした時刻」の遅いほう
- 1セット ＝ 作業25分×4 ＋ 休憩5分×3 ＋ 長い休憩（設定値、初期15分）。セットをくり返す
- 残り時間は「フェーズの終了」と「区間の終了」の早いほうまで（例：11:50開始の作業は12:00まで）
- OFFにした日付を保持し、日付が変わったら解除する
- 1秒ごとに再計算し、前回と状態が変わっていたら通知と画面更新を行う
- スリープ明けなどで複数の切り替わりをまたいだ場合、通知は現在の状態の分を1回だけ出す
- 祝日データがない年の日付は祝日ではないとして扱い、メイン画面に「祝日データの更新が必要です」と表示する

## 5. 画面

### メイン画面
- 状態、残り時間（大きく）、サイクル数（例：2 / 4）、ON/OFFボタン、設定ボタン
- 普段は閉じておき、必要なときだけ開く
- ×ボタンではアプリを終了せず、ウィンドウを隠すだけ

### 設定画面
- 就業開始・終了時刻、昼休憩開始・終了時刻（手入力）
- 長い休憩の長さ（分）
- 「ミニ表示を表示する」チェック（初期値ON）
- 「Windowsログイン時に自動起動する」チェック（初期値OFF）
- 保存・キャンセル。保存時に入力チェック（開始が終了より前か、昼休憩が就業時間内に収まっているか、長い休憩が1分以上か）
- 時刻は「9:00」の形式の文字で入力する。形式が正しくなければ、保存時にエラーを表示する
- タイマーの計算に関わる設定（就業開始・終了、昼休憩の開始・終了、長い休憩の長さ）が変わって保存したときは、ONにし直したときと同じ扱いにする（就業時間内なら、その時点から1サイクル目を開始。OFF中なら保存後にONになる）
- 「ミニ表示を表示する」「Windowsログイン時に自動起動する」だけが変わった場合は、設定を差し替えるだけで、タイマーの状態・ON/OFF・通知には影響させない

### ミニ表示
- 枠なし・常に最前面の小さなウィンドウを、タスクバーのすぐ上（画面右下）に置く
- 表示：状態の色（状態ごとに色分け）・状態名・残り時間・サイクル数（例：`● 作業中 18:32 2/4`）
- 左クリックでメイン画面を開く。右クリックでトレイと同じメニューを出す
- ドラッグで移動でき、位置は保存して次回も使う
- タスクバーに重ねる配置は今回は対象外

### タスクトレイ
- マウスを乗せると状態と残り時間を表示
- ダブルクリックでメイン画面を開く
- 右クリックメニュー：画面を開く ／ ON・OFF ／ 設定 ／ 終了

## 6. 保存

- 設定は JSON で `%AppData%\PomodoroTimer\settings.json` に保存（管理者権限不要）
- 自動起動はスタートアップフォルダへのショートカット作成・削除で実現する
